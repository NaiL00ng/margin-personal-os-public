# 余白 MARGIN · 四象限便利贴原型

`0.3.0-dev.2` 保留便利贴、动态艾森豪威尔矩阵、调整、完成和 Void，并加入本机 Python + SQLite 保存。当前不连接银行、不接入真实账单，也不实现完整记账功能。样式、脚本和装饰均在本地，无需外部网络或第三方包；此版本仍是开发预览。

## 选择本地入口

macOS 在使用已有 Swift 工具本机构建后，可在项目目录双击 `Margin.app`，自动进入下述数据库模式；仓库不附带生成应用，快捷入口、退出与构建方式见 [后端使用说明](backend-guide.md#图形启动器macos)。

**数据库模式**：使用 Python 3.9+ 在项目根目录运行 `python3 server.py`，打开 `http://127.0.0.1:4317`。首次是空看板，已确认记录保存在 `.local/margin.sqlite3`，备份在 `.local/backups/`。清除浏览器缓存不会删除数据库中的已确认记录。启动、保存状态和故障处理见 [后端使用说明](backend-guide.md)。

**静态模式**：构建后双击 [prototype.html](../prototype.html)，无需启动服务器；也可以保留同目录源文件后打开 [index.html](../index.html)，或运行 `node preview.mjs`。首次打开会生成四张示例便利贴，象限内示例的驻留计时从首次加载开始。Node 预览与 Python 服务默认使用同一端口，不能同时启动。

静态模式的记录使用浏览器 `localStorage`，按浏览器和来源隔离，不会自动进入数据库或同步到其他设备。`file://` 本地文件的存储范围由浏览器决定；移动或改名 HTML 文件、切换浏览器，可能看不到原来的记录。清除网站数据或使用临时浏览模式也可能使记录无法保留。

「记录册 → 导出完整记录」可以下载 JSON，保存卡片、外观、过程事件、归档快照与导出时的驻留统计。数据库入口另外提供「数据与备份」：旧 JSON 先预览、再确认合并；同 ID 内容冲突时拒绝覆盖。旧记录无法证明的历史保持未知，不把累计统计伪造成完整时间线。当前数据库的已有偏好不会因合并新卡片被静默替换。

数据库备份恢复与 JSON 导入不同：选择本机备份、预览并确认后，当前看板和历史被替换，恢复前自动创建安全备份。手动备份及恢复前备份已实现，定时／异地备份尚未实现。静态入口不提供数据库备份能力。

数据库模式以页面的保存状态为准；请求结果待确认时，用同一请求重试，不继续积压新的正式修改。它不是离线写入队列，也不会静默转为浏览器保存。未提交文字只在当前窗口保留，没有持久表单草稿；静态存储失败或跨窗口冲突时则按提示导出本页记录。

## 便利贴与操作

看板左上是重要不紧急，右上是重要紧急，左下是不重要不紧急，右下是不重要紧急。小卡只显示标题与时间数字：在象限中表示该象限累计驻留，在准备区表示全部象限累计驻留（暂停）。长标题会截断显示，点击可读完整内容。

在象限内拖动可自由摆放，刷新后保留各象限的位置；同象限挪动不会打断计时。页面缩放时按相对位置调整并限制在画布内。卡片重叠时可点击「整理位置」，或用 Tab 聚焦并置前。

- **新建**：标题必填，最多 28 个字符；描述可选，最多 120 个字符；分类必填，自定义分类最多 12 个字符。长度按 Unicode 码点计算，部分组合表情可能占多个字符。
- **放入象限**：从准备区拖入四象限，成功落位才开始驻留计时。卡片的纸色、旋转角度与小符号在创建时随机生成，后续调整与恢复保留原外观。
- **调整**：拖入「调整」或在卡片详情选择调整。编辑期间暂停计时，卡片静态暂留于松手终点；保存、取消、Esc、关闭或点击遮罩关闭窗口后，均移到准备区。取消只放弃本次文字修改，旧内容与累计驻留保留。重新放入象限才继续计时。
- **完成**：拖入「完成」或使用卡片按钮。卡片停止计时，保存当次完整快照并进入已完成记录。
- **Void**：拖入 Void，停留满 **1.2 秒后松手**才确认取消；提前松手、移开或中止拖拽不取消。也可点击卡片打开详情，选择 Void 后通过明确的确认按钮取消，并可填写原因。
- **恢复**：记录册中的最近一次结束记录可恢复到准备区。恢复保留累计驻留时间；此前完成或取消的标题、描述、外观与时长快照仍然保留，后续修改不会覆盖当时的记录。

点击卡片可查看详情与各象限驻留占比，也能直接用按钮移动，作为拖拽之外的操作方式。键盘可用 `Tab` 聚焦、`Enter` 打开操作、`N` 新建，`Esc` 关闭窗口或中止拖拽。

非输入区域不支持文字选择；名称、描述、自定义分类等输入框仍可正常选中、复制和编辑文字。

## 计时含义

这里记录的是**卡片在象限中的驻留时间，不是专注或实际工作时间**。多张卡片可以同时驻留，因此不能把总和当作实际投入的工时。

每个象限分别累计；准备区与编辑期间暂停；完成或取消后冻结。当卡片仍在象限中时，**刷新、关闭网页或关闭本机服务期间也按经过的墙钟时间累计**，重新打开会从保存的时间戳计算。数据库模式由服务端动作时间结算，页面每秒刷新显示；同象限挪动不重置起点。它不依赖后台秒表持续运行，也不推断你离开页面后是否真的在做这件事。

## 外观与动效

动效有三挡：「灵动」提供纸面伪 3D、高光、生成反馈、完成在松手处抖动缩小、调整暂留后移回与 Void 炭化烧边；「轻柔」使用短暂淡入淡出；「关闭」直接更新状态。默认尊重系统“减少动态效果”偏好，可在设置中调整。设置会本地保存，更改强度不会改变卡片结果或计时。四象限颜色也可在设置中修改。

## 源文件与构建

| 文件 | 作用 |
| --- | --- |
| [index.html](../index.html) | 页面结构及源文件引用 |
| [style.css](../style.css) | 页面、便利贴和响应式样式 |
| [model.js](../model.js) | 静态模式业务模型；数据库模式的状态读取与驻留展示 |
| [effects.js](../effects.js) | 装饰性动效，不管理业务数据 |
| [storage.js](../storage.js) | 数据库请求、版本冲突与待确认请求重试 |
| [app.js](../app.js) | 界面、拖拽、操作确认及两种保存入口的适配 |
| [server.py](../server.py)、[backend/server.py](../backend/server.py) | 本机 Python 入口与 HTTP 适配 |
| [backend/store.py](../backend/store.py) | SQLite 事务、驻留、历史、导入与备份恢复 |
| [build.mjs](../build.mjs) | 零依赖的单文件构建脚本 |
| [model.test.cjs](../model.test.cjs)、[storage.test.cjs](../storage.test.cjs) | 模型与请求层测试 |
| [backend/test_store.py](../backend/test_store.py)、[backend/test_server.py](../backend/test_server.py) | 存储与 HTTP 测试，使用合成数据 |

先阅读 [build.mjs](../build.mjs)，再在项目根目录运行：

```sh
node build.mjs
```

脚本只读取 `index.html`、`style.css`、`model.js`、`effects.js`、`storage.js`、`app.js` 六个前端源文件，并写入同目录 `prototype.html`；重复运行会替换该生成文件，不修改源文件。没有安装、网络访问或源脚本执行，也不包含 Python 和数据库。构建要求 HTML 中的引用完全匹配且仅出现一次，缺失、重复或存在未打包引用时会停止。内联脚本保留原执行顺序并放在页面末尾，处理脚本结束标签，避免内联内容提前关闭脚本元素。
