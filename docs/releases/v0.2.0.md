## 设计与实现

使用紧凑标题、共同区域和渐进揭示建立视觉层级，把主要空间交给矩阵。空间记忆有邻近研究支持，但本产品的查找效率、主观负担和长期效果仍待验证，见 [证据登记](../research/evidence-register.md)。

参考 [Godot Fake3D Demo](https://github.com/Fulafu-ai/Godot4-Fake3D-Card-Game-UI-Demo) 的指针透视与溶解边缘机制；本版本使用原创 CSS 变换、轮廓裁切和 Canvas 绘制，没有复制其源码/素材，也没有增加运行时或插件。参考仓库根许可证与单独 Shader 文件许可并不相同，未来若直接复用需要按具体文件核查。

## 兼容与边界

继续读取 `margin.matrix.v1`，原卡片、象限累计及归档不重置。新增可选归一化位置字段。旧版程序可能在保存时丢弃这个字段，回退前导出完整记录。

没有加入后端、真实账单或新行为干预模块。卡片很多时允许重叠；可整理或用键盘逐张聚焦。完整 Void 悬停、真机触屏及低性能设备动画仍需进一步验收。具体已执行检查见 [验证记录](../quality/validation.md)。
