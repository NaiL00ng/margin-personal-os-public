本版为现有四象限便利贴加入 Python + SQLite 保存、旧数据导入和本机备份恢复，保留看板、自由摆放、调整暂留、完成、Void 和三档动效。它仍不是完整个人管理与记账产品。

dev.2 将第三象限改名为“安排妥当”，新增 macOS `Margin.app`：双击检查或启动本机服务，打开默认浏览器；复用时验证项目与数据库身份，退出只停止自身创建的服务。应用和缓存仅在本地；Swift、Python 源码及构建方法可复查，具体见 [后端指南](../backend-guide.md)。dev.1 源码包仍保存在 `.local/versions/0.3.0-dev.1/`。

## 已实现

- Python 3.9+ 标准库 `http.server`、`sqlite3`、`unittest`，不安装 FastAPI 等依赖。`python3 server.py` 默认仅监听 `127.0.0.1:4317`。
- `.local/margin.sqlite3` 保存卡片、分类、设置、过程事件、结束快照及驻留记录；新库从空看板开始。
- 动作使用服务端时间，在事务中更新；同象限移动不重新起算，编辑进入准备区暂停，完成／取消冻结，恢复保留累计与旧快照。关闭网页或服务期间仍算墙钟驻留，不是实际工时。
- 全局 revision 防止旧状态覆盖；operationId 绑定完整请求，重试不重复写入。界面区分已保存、等待、结果待确认和冲突，未知结果通过原请求重试。
- 「数据与备份」预览校验旧 JSON 后确认合并，保留 ID、外观、位置、累计和已有历史。重复来源不重复导入，冲突拒绝覆盖；缺失历史保持未知，派生统计不重复累计。
- 手动创建 SQLite 一致性备份；预览确认恢复替换当前领域记录，恢复前自动保留当前库的安全备份。数据库身份与幂等回执保留，重复恢复请求不重复覆盖。
- 本机 Host／Origin／令牌校验与静态文件白名单；私有数据库和备份不通过静态路径提供。
- 保留静态入口及原模型测试，增加请求层、Python 存储和 HTTP 测试。实际运行结果和未测范围见 [验证记录](../quality/validation.md)，不以文档存在代替测试通过。

## 两种入口与旧数据

数据库入口使用 `python3 server.py`，详见 [后端指南](../backend-guide.md)。双击 `prototype.html`／`index.html` 或运行 Node 静态预览仍使用独立的浏览器 `localStorage` 和初次示例，不会自动迁移 SQLite。两种服务的默认端口相同，不能同时启动。

旧静态数据先导出 JSON，再在数据库入口预览和确认导入；不会自动删除浏览器原记录。**JSON 导入是合并，数据库备份恢复是替换**。备份默认放在 `.local/backups/`；源码版本保留和数据备份需要分别管理。

静态构建读取 `index.html`、`style.css`、`model.js`、`effects.js`、`storage.js`、`app.js` 六个源文件，生成单文件；不包含 Python 后端、数据库或备份。

## 当前边界

- 只有数据库 schema 1；未知 schema 拒绝打开，未来版本迁移尚未实现，不通过删库重建升级。
- 没有离线写入队列、跨设备同步、持久表单草稿、定时／异地备份、数据加密或公网账户。
- 没有生命月历、日程联动、真实账单导入、银行连接或完整财务模块。
- 本机安全措施不是公网部署方案，同盘备份不能应对整盘损坏。
- 触屏和跨浏览器广泛兼容性、长期使用负担与行为效果仍有未验证范围；本版不宣称改善习惯或心理福祉。
